POST /v1/slug

URL-safe slug from arbitrary text.

NFKD-normalizes, strips diacritics and quotes, replaces non-alphanumerics with the separator, collapses repeats, optionally lowercases.

fieldtype
textstringrequired
separatorstringoptional, default `"-"`Non-empty replacement for non-alphanumeric runs.
lowercasebooleanoptional, default `true`Set false to preserve letter case.
# verified this build — run it
curl -sS -X POST https://rapidapi-roan.vercel.app/v1/slug \
  -H 'Content-Type: application/json' \
  -d '{"text":"Hello World Example"}'

response on this run (200, X-Response-Time 0ms):

{
  "slug": "hello-world-example"
}

POST /v1/html-to-text

Strip HTML to plain text.

Removes script, style and comment blocks; block-level closing tags become newlines; decodes common named and numeric entities; collapses whitespace runs; trims.

fieldtype
htmlstringrequired
# verified this build — run it
curl -sS -X POST https://rapidapi-roan.vercel.app/v1/html-to-text \
  -H 'Content-Type: application/json' \
  -d '{"html":"<h1>Title</h1><p>Hello &amp; welcome.</p>"}'

response on this run (200, X-Response-Time 0ms):

{
  "text": "Title\nHello & welcome."
}

POST /v1/case

Convert text between cases.

`upper`, `lower`, `title` operate on the input string directly. `camel`, `pascal`, `snake`, `kebab` first split on non-alphanumerics and camelCase boundaries, then rejoin.

fieldtype
textstringrequired
tostring, one of `upper` | `lower` | `title` | `camel` | `pascal` | `snake` | `kebab`required
# verified this build — run it
curl -sS -X POST https://rapidapi-roan.vercel.app/v1/case \
  -H 'Content-Type: application/json' \
  -d '{"text":"Hello World Example","to":"camel"}'

response on this run (200, X-Response-Time 0ms):

{
  "result": "helloWorldExample"
}
